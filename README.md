# AI Resume Analyzer

This is a Python project that checks a resume against a job description.

It reads the resume PDF, finds skills, compares them with the skills mentioned in the job description, and gives a match score.

## Features

- Upload resume PDF
- Extract text from resume
- Find skills from resume
- Add job description
- Find matching skills
- Find missing skills
- Show ATS match score
- Give simple suggestions

## Technologies

- Python
- Streamlit
- PyMuPDF
- JSON
